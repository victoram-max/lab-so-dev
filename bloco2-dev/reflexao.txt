# ATIVIDADE 6 — Make

# 1. O monitor histórico verificava a conclusão de cada job antes
#    de despachar o próximo. No make, qual mecanismo cumpre esse
#    papel? Como o make sabe que não precisa recompilar um arquivo
#    que não mudou?

Resposta 1:O sistema de dependências e a verificação da data de modificação dos arquivos.O make olha se algum arquivo foi 
modificado depois da última compilação e se nada mudou, ele entende que não precisa recompilar tudo de novo.


# 2. O monitor unificava "supervisor, carregador e rotinas de I/O
#    sob uma interface textual". O que o Makefile unifica no fluxo
#    de desenvolvimento moderno?

Resposta 2:O Makefile unifica a compilação, execução de comandos e organização das dependências
